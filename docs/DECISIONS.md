# Журнал решений

Формат: номер, дата, решение, причина, последствия.

## D-001 · 2026-10-24 · Astro + TypeScript, статическая генерация

**Решение:** сайт на Astro с TypeScript, `output: 'static'`; интерактивность — только точечными скриптами.
**Причина:** SEO-ориентированный сайт с отдельными страницами калькуляторов; статика быстрая и бесплатно хостится.
**Последствия:** нет серверной части; БД, регистрация и личные кабинеты требуют отдельного решения.

## D-002 · 2026-10-24 · URL калькуляторов `/kalkulyatory/<slug>/`

**Решение:** плоская схема на транслите, не зависящая от категории; `trailingSlash: 'always'`.
**Причина:** перенос калькулятора между категориями не должен ломать URL; транслит читаем в выдаче.

## D-003 · 2026-10-24 · Каталог как единый типизированный источник

**Решение:** `src/data/calculators.ts` + `catalog.types.ts`; ссылки — только для `status: 'available'`.
**Причина:** нельзя показывать ссылки на несуществующие страницы; главная, поиск и sitemap используют одни данные.

## D-004 · 2026-10-24 · Версии инструментов под Node.js 22.22.0

**Решение:** зафиксированы точные версии: astro 7.4.1, typescript 5.9.3, @astrojs/check 0.9.12,
vitest 5.0.5, eslint 10.13.0, typescript-eslint 8.72.0, eslint-plugin-astro 1.7.0, prettier 3.9.10,
prettier-plugin-astro 1.1.2. `.nvmrc` = 22.22.0, `engines.node` ≥ 22.22.0.
**Причина:**

- astro 7.4.2 требует Node ≥ 22.23.4, а в облачной среде Node 22.22.0;
- eslint-plugin-astro 2.x/3.x требуют Node ≥ 22.22.3;
- TypeScript 7 не поддерживается @astrojs/check (^5 || ^6) и typescript-eslint (< 6.1);
- ESLint 9 помечен как неподдерживаемый, поэтому ESLint 10.
  **Последствия:** при обновлении Node в среде можно поднять astro и eslint-plugin-astro.

## D-005 · 2026-10-24 · Без UI-фреймворков, системные шрифты, собственные CSS-токены

**Решение:** без React/Vue/Tailwind и веб-шрифтов; CSS-переменные в `tokens.css`.
**Причина:** минимальный вес страниц, мало зависимостей; задачам этапа хватает встроенных средств Astro.

## D-006 · 2026-10-24 · Playwright — локальный скрипт, не зависимость

**Решение:** `scripts/ui-check.mjs` использует предустановленный в среде Playwright; в CI не входит.
**Причина:** не тянуть браузеры (~сотни МБ) в зависимости и CI на этапе каркаса.
**Пересмотреть:** на этапе 4 (подготовка к публикации) — добавить e2e в CI.

## D-007 · 2026-10-24 · Поиск по каталогу на клиенте

**Решение:** поиск фильтрует уже отрисованные карточки по индексу, собранному при сборке; логика общая с тестами.
**Причина:** каталог маленький; не нужен поисковый сервис или библиотека. Без JS поле поиска скрыто.
