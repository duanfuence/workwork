# Стратегия тестирования

## Уровни

| Уровень   | Инструмент                                          | Где                           | Когда запускается                            |
| --------- | --------------------------------------------------- | ----------------------------- | -------------------------------------------- |
| Типы      | `astro check` (TypeScript strictest)                | весь проект, включая `.astro` | `npm run typecheck`, CI                      |
| Линтер    | ESLint 10 + typescript-eslint + eslint-plugin-astro | весь проект                   | `npm run lint`, CI                           |
| Формат    | Prettier + prettier-plugin-astro                    | весь проект                   | `npm run format:check`, CI                   |
| Unit      | Vitest 5                                            | `src/**/*.test.ts`            | `npm test`, CI                               |
| Сборка    | `astro build`                                       | —                             | `npm run build`, CI                          |
| Интерфейс | Playwright + Chromium                               | `scripts/ui-check.mjs`        | вручную: `npm run build && npm run ui:check` |

`npm run check` запускает первые пять уровней в том же порядке, что и CI.

## Проверка интерфейса (`npm run ui:check`)

Запускает `astro preview`, открывает главную в Chromium при 390×844 (мобильный, touch) и 1440×900, проверяет:

- статус 200, `lang="ru"`, UTF-8, `title`, `description`, `viewport`, `og:title`, единственный `h1`;
- кириллицу в `h1`;
- отсутствие горизонтальной прокрутки;
- 6 карточек «Скоро» без ссылок; все внутренние ссылки и якоря существуют;
- мобильное меню: открытие, `aria-expanded`, переход к разделу, закрытие по Escape; на широком экране — видимые ссылки;
- поиск: «плит», «шпаклевка» без «ё», «стены», «бетон» (пустой результат), очистка;
- отсутствие ошибок в консоли; ответ 404 для ещё не созданной страницы калькулятора.

Скриншоты сохраняются в `.ui-check/` (в `.gitignore`) или в папку из аргумента.
Playwright не входит в зависимости: в облачной среде он предустановлен. В CI не запускается (см. `DECISIONS.md`, D-006).

## Правила для калькуляторов (с этапа 2)

- Формула — чистая функция в `src/lib/calculators/`, тест рядом.
- Минимум: 2–3 контрольных примера, посчитанных вручную и записанных в тесте с пояснением;
  граничные значения (ноль, очень большие размеры, проёмы больше стены); округление вверх до целых упаковок.
- Недопустимый ввод — явная ошибка/сообщение, а не `NaN` в интерфейсе.
- Тесты не подгоняются под текущий результат кода — ожидаемые значения считаются независимо.
