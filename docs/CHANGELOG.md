# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — 2026-10-24 — Этап 2: калькулятор обоев

### Добавлено

- Страница `/kalkulyatory/oboi/` с калькулятором обоев: размеры комнаты, окна и двери, параметры рулона,
  раппорт, подрезка, цена; результат с периметром, площадями, полосами, длиной полосы, полосами из рулона,
  рулонами и стоимостью; пересчёт без перезагрузки; объяснение метода, формулы, ограничения, FAQ.
- Расчётные модули `src/lib/calculators/wallpaper.ts`, `wallpaper-form.ts`, вспомогательные
  `src/lib/number.ts`, `src/lib/format.ts`; формы слов «рулон», «полоса».
- Компоненты `NumberField`, `Breadcrumbs`; стили `src/styles/calculator.css`; кнопки `.button`;
  токены `--color-danger`, `--color-danger-soft`.
- Документ `docs/calculators/WALLPAPER.md`: алгоритм, допущения, контрольные примеры.
- Тесты: 114 (было 34). UI-проверка расширена до 4 ширин и страницы калькулятора (267 проверок).

### Изменено

- Калькулятор обоев переведён в статус `available`: карточка на главной ведёт на страницу и показывает «Рассчитать →».
- Тексты главной и сводка категорий учитывают опубликованные калькуляторы.
- Анонимная телеметрия Astro отключена в npm-скриптах и CI.

### Исправлено

- Горизонтальная прокрутка 5 px на ширине 320 px (формула в `<code>` не переносилась).

## [0.1.0] — 2026-10-24 — Этап 1: технический каркас

### Добавлено

- Проект Astro 7.4.1 + TypeScript (strictest), статическая генерация, `package-lock.json`.
- Дизайн-токены (`src/styles/tokens.css`) и базовые стили.
- Главная страница: название, описание, поиск по каталогу, «Популярные инструменты»
  (6 калькуляторов первой очереди со статусом «Скоро», без ссылок), 4 категории, «О сервисе»,
  адаптивная навигация, футер. Страница 404.
- Типизированный каталог калькуляторов и категорий, функции выборки и поиска.
- Vitest (34 теста), ESLint, Prettier, `astro check`, скрипт `npm run check`.
- GitHub Actions: типы, линтер, форматирование, тесты, сборка.
- Скрипт проверки интерфейса `npm run ui:check` (Playwright, 390 px и 1440 px).
- `CLAUDE.md` и документация в `docs/`.
