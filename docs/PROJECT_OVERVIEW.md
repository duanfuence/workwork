# Обзор проекта

## Что это

**ДомРасчёт** — бесплатный русскоязычный сайт домашних, ремонтных и строительных калькуляторов
для пользователей из России. Каждый калькулятор — отдельная страница со своим URL, оптимизированная
под поисковые запросы вида «калькулятор обоев», «сколько ламината нужно на комнату».

## Для кого

Люди, которые делают ремонт сами или контролируют бригаду: нужно быстро понять, сколько материала
купить, часто прямо с телефона в магазине или на объекте.

## Направления каталога

| Категория        | id             | Статус                                 |
| ---------------- | -------------- | -------------------------------------- |
| Ремонт и отделка | `repair`       | обои готовы, 5 в первой очереди        |
| Строительство    | `construction` | калькуляторы не запланированы детально |
| Площади и объёмы | `area-volume`  | калькуляторы не запланированы детально |
| Стоимость работ  | `cost`         | калькуляторы не запланированы детально |

Первая очередь: обои (**готов**, `/kalkulyatory/oboi/`), ламинат, краска, плитка, шпаклёвка,
штукатурка (статус `planned`, страниц нет).

В дальнейшем: общие сметы, сохранение проектов, личные кабинеты (не раньше, чем появится
стабильный набор калькуляторов; см. `ROADMAP.md`).

## Принципы продукта

- Бесплатно и без регистрации.
- Прозрачные формулы: пользователь видит, из чего складывается результат.
- Мобильная версия — основная, а не второстепенная.
- Честность интерфейса: нет фиктивных функций и ссылок на несуществующие страницы.
- Лёгкие страницы: статический HTML, минимум JavaScript, без случайных изображений.

## Текущий статус (этап 2.1 завершён)

- Технический каркас на Astro + TypeScript, дизайн-токены, главная страница, каталог и поиск.
- Первый калькулятор — обои: расчёт по полосам с раппортом, подрезкой, окнами и дверями, стоимостью;
  математика прошла независимый аудит (этап 2.1), формы калькуляторов используют общий механизм.
- Тесты Vitest (154), ESLint, Prettier, проверка типов, GitHub Actions, UI-проверка в Playwright.
- Сайт нигде не опубликован, домена нет.
