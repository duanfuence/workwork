# Калькулятор плитки: модель, допущения, контрольные примеры

Код: `src/lib/calculators/tile.ts` (расчёт), `tile-form.ts` (разбор полей формы).
Тесты: `tile.test.ts` (контрольные примеры Т1–Т6, границы, ошибки ввода), `tile-form.test.ts`.
Страница: `src/pages/kalkulyatory/plitka.astro` → `/kalkulyatory/plitka/`.

Версия модели: **1** — прямая укладка «шов в шов» по сетке.

## Входные данные

| Поле                                    | Единица | Обязательное | Допустимо                                  | Пусто                 | В форме |
| --------------------------------------- | ------- | ------------ | ------------------------------------------ | --------------------- | ------- |
| Тип поверхности                         | —       | да           | пол / стена                                | —                     | пол     |
| Длина поверхности `X`                   | м       | да           | 0,1–100                                    | ошибка                | —       |
| Ширина поверхности `Y` (стена — высота) | м       | да           | 0,1–100                                    | ошибка                | —       |
| Одинаковых поверхностей `k`             | шт.     | да           | целое 1–50                                 | ошибка                | 1       |
| Длина плитки `a` (вдоль `X`)            | мм      | да           | целое 20–3000                              | ошибка                | —       |
| Ширина плитки `b` (вдоль `Y`)           | мм      | да           | целое 20–3000                              | ошибка                | —       |
| Шов `j`                                 | мм      | нет          | 0–20, не больше одного знака после запятой | 0                     | 2       |
| Запас `z`                               | %       | нет          | 0–50, не больше одного знака после запятой | 0                     | 10      |
| Плиток в упаковке `p`                   | шт.     | нет          | целое 1–1000                               | упаковки не считаются | —       |

Тип поверхности меняет только подписи: формула для пола и стены одна.

## Модель

Плитки кладутся рядами от угла, шов в шов, длинной стороной плитки `a` вдоль `X`.

1. В ряду из `n` плиток `n` плиток и `n − 1` швов покрывают `n·a + (n − 1)·j`. Нужно `n·a + (n − 1)·j ≥ X`, отсюда
   **`n_X = ⌈(X + j) / (a + j)⌉`**; так же **`n_Y = ⌈(Y + j) / (b + j)⌉`**.
2. Плиток на поверхность — `n_X · n_Y`: каждая клетка сетки, в том числе подрезанная у края, — отдельная плитка;
   обрезки в другие клетки не переносятся. Всего **`N = k · n_X · n_Y`**.
3. С запасом **`N_з = ⌈N · (100 + z) / 100⌉`** — целое число плиток.
4. Упаковок **`⌈N_з / p⌉`**, к покупке `⌈N_з / p⌉ · p` плиток.
5. Справочно: площадь облицовки `S = k · X · Y` и «по площади» `⌈S / (a · b)⌉` — без швов, подрезки и раскладки;
   на число плиток не влияет.

Целые единицы: длины — десятые доли мм (шов задаётся с шагом 0,1 мм), запас — десятые процента. Деления — целочисленные:
двоичные дроби не дают лишней плитки (Т2, Т6).

## Допущения и ограничения (сказать на странице)

- Это оценка по сетке для прямоугольной поверхности, а не раскладка: калькулятор не знает, откуда начинается укладка,
  где пройдут швы и какие плитки придётся резать. Раскладка «от центра» или симметричная подрезка у обеих стен может
  добавить ряд в каждом направлении.
- Обрезки не используются повторно: если кусок от крайней плитки подходит на другой край, плиток понадобится меньше.
- Не учитываются: диагональная укладка, разбежка («кирпичиком»), рисунки из плиток разного размера, совмещение
  рисунка, бой при резке, проёмы, трубы, ниши и короба — их покрывает запас.
- Ориентация плитки — как введена (длина плитки вдоль длины поверхности); при другой ориентации результат может быть
  другим — поменяйте размеры местами.
- Несколько разных поверхностей в одном расчёте не поддерживаются: одинаковые — через `k`, разные — отдельными
  расчётами (будущее расширение).

Т2 показывает, что при точном попадании в сетку лишнего ряда нет, а расчёт «по площади» без швов даёт больше:
швы тоже покрывают поверхность. Т6 проверяет отсутствие лишней плитки из-за двоичных дробей.

Ошибки ввода: размеры 0, −1, пусто, больше 100 м; плитка 19 мм, 3001 мм, 300,5 мм; шов −1, 21, 2,55 мм; поверхностей
0 и 1,5; запас 5,55 и 51 %; в упаковке 0 и 1,5.
