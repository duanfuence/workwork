## 1. Задача

Сколько упаковок ламината купить для одной прямоугольной комнаты, чтобы хватило при выбранной схеме смещения
стыков и требованиях производителя к длине отрезков. Пользователь должен понимать, что расчёт строит
**геометрический план раскладки** на идеальном прямоугольнике; неровные стены, трубы, дверные коробки,
порожки и ошибки резки добавляют расход — на это и нужен процентный запас.

## 2. Сравнение подходов

### Подход A — по площади

`доски = ⌈(L · W) / (l · w)⌉`, затем запас и целые упаковки.

**Когда даёт меньше, чем план раскладки** (все случаи — реальная геометрия, не погрешность). Сравниваются
целые доски **без запаса** (`B_A` и `B`) и упаковки без запаса; если запас указан, он применяется к обоим одинаково.

1. **Последний ряд неполной ширины.** Ряд из целых досок нужен целиком, отрезанная вдоль полоса уходит в отход.
   Комната шириной 1,05 м при доске 200 мм: 6 рядов, а площадь «видит» 5,25 (пример К3: 11 по площади, 12 по рядам).
2. **Короткие концы рядов.** Отрезок короче минимального (обычно 20–40 см по инструкции) ставить нельзя —
   ряд приходится сдвигать, и с обоих концов появляются обрезки, которые некуда применить (К2: 11 → 13).
3. **Профиль замка.** Отрезанная часть доски годится только для одного конца ряда (см. §4.1), поэтому
   обрезки не взаимозаменяемы, как предполагает площадь.
4. **Ряд короче доски или неудачная длина ряда.** Комната 3,6 × 1,3 м поперёк: ряды по 1,3 м из досок 1,2 м
   дают 27 досок против 20 по площади (К5).
5. **Реальная комната 4,0 × 3,5 м, доска 1380 × 193, 8 в упаковке**: по площади 53 доски = 7 упаковок,
   а план раскладки вдоль длины по любой из трёх схем — 57 досок = 8 упаковок; «площадь + 5 %» (56 досок)
   меньше этого плана (К13). Это свойство **конкретного направления и схем**, а не комнаты: поперёк со схемой 1/3
   план даёт 56 досок = 7 упаковок (§10). Нижняя граница по материалу для этих рядов — 56 досок, поэтому
   утверждать, что 7 упаковок «не хватит» при любой раскладке, нельзя.

Процент «на подрезку» к площади (обычно советуют 5–10 %) закрывает эти потери не всегда: в маленьких и узких
комнатах они доходят до 25–40 % (К2 — 25 %, К10 — 30 %, К5 — 38 %), а в удачных — 0 % (К1, К7, К11), и тогда процент — переплата.

### Подход B — по рядам

Комната делится на ряды шириной доски. Для каждого ряда определяются начальный отрезок, целые доски и конечный
отрезок; затем считается, сколько досок нужно, чтобы вырезать все отрезки с учётом профиля замка
(обрезок одного ряда может стать отрезком другого).

**Когда уменьшает отходы** по сравнению с «площадь + фиксированный процент»: когда длина ряда и схема
смещения позволяют использовать обрезок одного ряда в другом — например, в схеме «от обрезка» при удачной
длине комнаты отходов почти нет (К9: 9 досок = площадь), и запас «на подрезку» не нужен.

**Какие данные нужны для достоверной раскладки:** рабочие (без замка) размеры доски; минимальная длина
отрезка и минимальное смещение стыков **из инструкции производителя**; допустимые схемы смещения; форма
комнаты с нишами и выступами; положение дверных проёмов и порогов, труб и колонн; компенсационный зазор;
ширина пропила; от какой стены и в какую сторону начинается укладка; кривизна стен.

**Какие ограничения останутся даже при расчёте по рядам:** комната — идеальный прямоугольник; препятствия
и проёмы не учитываются; **ряды** выбираются по правилу схемы (§4.3), и другой выбор рядов (другая схема,
сдвиг, направление, стартовая стена) может дать меньше досок — общий минимум не ищется и не утверждается.
Минимален только подсчёт досок **для уже выбранных рядов** (§4.4); брак и ошибки резки не моделируются;
монтажник может разложить иначе — экономнее или расточительнее.

### Вывод

Подход A в качестве основного результата **не годится**: в рамках модели план по рядам никогда не меньше
площади (`B ≥ ⌈N·R / l⌉ ≥ B_A`, §10), а в узких, маленьких и «неудачных» по длине комнатах больше (в примерах — на 7–35 %).
Это свойство модели, а не универсальная граница: реальная укладка с зазором у стен покрывает чуть меньшую
площадь, а мастер может выбрать другие ряды. Основной результат версии 1 — **подход B**;
результат по площади показывается справочно, чтобы пользователь видел, почему цифра отличается
от «калькулятора по площади» в магазине. Двух режимов на выбор пользователя нет: режим по площади
предлагал бы заведомо заниженный вариант.

## 3. Обозначения и единицы

Все длины — в **целых миллиметрах** (`Math.round`), как в калькуляторе обоев. Ввод — в метрах (комната)
и миллиметрах (доска: так размеры указаны на этикетке).

| Обозначение | Смысл                                                        | Ввод               |
| ----------- | ------------------------------------------------------------ | ------------------ |
| `L`, `W`    | длина и ширина комнаты                                       | м                  |
| `l`, `w`    | длина и ширина доски (рабочие, без замка)                    | мм                 |
| `n`         | досок в упаковке                                             | шт.                |
| направление | ряды вдоль длины `L` или вдоль ширины `W`                    | выбор              |
| схема       | «1/2», «1/3», «от обрезка»                                   | выбор              |
| `m`         | минимальная длина отрезка, по умолчанию 400                  | мм (дополнительно) |
| `o`         | минимальное смещение стыков соседних рядов, по умолчанию 400 | мм (дополнительно) |
| `z`         | дополнительный запас                                         | % (0–50, шаг 0,1)  |
| цена        | цена упаковки, необязательно                                 | ₽                  |

Производные: длина ряда `R` = `L` (вдоль длины) или `W` (вдоль ширины); поперечный размер `D` — другой;
число рядов `N = ⌈D / w⌉`; ширина последнего ряда `r = D − (N − 1)·w`; площадь доски `l·w`, упаковки `n·l·w`.

`m` и `o` вынесены в поля «Требования производителя» с подсказкой: значения различаются у разных покрытий
(встречаются 200–400 мм), одна схема не подходит ко всем покрытиям. Значение по умолчанию — **строгое (400 мм)**:
план, допустимый при 400 мм, допустим и для покрытий с требованием 200–300 мм, обратное неверно. При значении
ниже требования производителя план может содержать запрещённые отрезки и занизить расход. Контрольные примеры
§8 задают `m = o = 300` явно.

## 4. Модель раскладки

### 4.1 Профиль замка и обрезки

Ряд укладывается слева направо: **начальный отрезок** у левой стены, целые доски, **конечный отрезок**
у правой стены. При поперечном резе доски получаются две части:

- **правая часть** (заводской торец справа) — годится только как **начальный** отрезок ряда;
- **левая часть** (заводской торец слева) — только как **конечный** отрезок.

Средняя часть (оба торца срезаны) в ряд не встаёт. Разворот доски на 180° меняет и длинные кромки,
поэтому не допускается. Отсюда главное правило модели: **из одной доски — не больше одного начального
и одного конечного отрезка**. Обрезок может геометрически подходить, но не подходить по профилю: правая часть
длиной 300 мм не станет конечным отрезком 300 мм (К2, §10). Отрезок короче `m` в план не ставится.

Если у покрытия торцевые замки одинаковы с обеих сторон, правило избыточно строгое — расчёт в сторону запаса.

### 4.2 Ряд

Для ряда с началом `s` (0 < s ≤ l):
`f = ⌊(R − s) / l⌋` целых досок, конечный отрезок `e = (R − s) mod l`.
Ряд допустим, если `s ≥ m` и (`e = 0` или `e ≥ m`); сумма отрезков ряда `s + f·l + e = R` всегда.
Стыки ряда — в точках `s + k·l`; смещение относительно соседнего ряда — круговое расстояние
`δ = min((s₁ − s₂) mod l, l − (s₁ − s₂) mod l)`, требуется `δ ≥ o`. Проверка по всем остаткам `mod l` строже
необходимой (учитывает и стыки за пределами ряда) — в сторону запаса.

### 4.3 Схемы смещения

- **Прямая укладка без смещения** (стыки соседних рядов на одной линии) **не поддерживается**: большинство
  производителей плавающих полов её запрещает. Под «без заданного смещения» в версии 1 понимается схема
  «от обрезка».
- **1/2**: начала рядов по циклу `[l, l − ⌊l/2⌋]`. Смещение ≈ l/2; ряды через один совпадают — это допустимо.
- **1/3**: цикл `[l, l − t, l − 2t]`, `t = ⌊l/3⌋` («лесенка»). Смещение ≈ l/3.

  Для обеих схем, если концы рядов получаются короче `m`, все ряды **сдвигаются на одно и то же** `d`:
  `s' = ((s − d − 1) mod l) + 1` — начало, ставшее ≤ 0, переносится на `l` (это равносильно смене типа
  первого ряда в цикле). Перебираются `d = 0, 1, …, l − 1`; выбирается **наименьшее**, при котором каждый ряд
  цикла допустим. Сдвиг не меняет смещение между рядами. Если такого `d` нет — строгая схема невыполнима для этих
  размеров (сообщение пользователю с причиной и предложением другой схемы). Если `⌊l/2⌋ < o` (или `t < o`,
  `l − 2t < o`) — схема невыполнима для этой доски. Перебор всех `d` с выбором меньшего числа досок проверялся
  на всех примерах (§10) и не дал выигрыша; в версии 1 он не нужен.

- **От обрезка** (ряд начинается обрезком конца предыдущего): начало ряда `i + 1` — **естественный обрезок**
  `l − eᵢ`, если `eᵢ > 0` и с этим началом ряд допустим, а смещение с рядом `i` не меньше `o`. Иначе — первое
  подходящее из `l, l − 1, …, m` (целая доска или свежий отрез). Первый ряд — первое подходящее из того же
  списка, без проверки смещения. Если ни одно начало не подходит, расчёт останавливается с сообщением, в каком
  ряду и почему (смещение или длина отрезка), и предложением другой схемы — «похожая» раскладка не подбирается.

  Свойство: если каждый ряд берёт обрезок предыдущего, смещение между рядами постоянно и равно
  `min(R mod l, l − R mod l)`. При `R mod l` близком к 0 или `l` стыки сходятся, и срабатывает пункт (2) (К8).

### 4.4 Расход досок (общий для всех схем)

Ряды уже выбраны (§4.3). Из них получаются:

- `F` — целые доски: в каждом ряду `f` штук, плюс начало `s = l` (целая доска) — ещё одна;
- `S` — список начальных отрезков `s < l`; `E` — список конечных отрезков `e > 0`;
- `M` — **наибольшее** число пар «начальный + конечный», которые можно вырезать из одной доски: `s + e ≤ l`
  (левая часть `e` — конец одного ряда, правая `s` — начало другого, середина — в отход).

**`B = F + |S| + |E| − M`.** Каждая пара — одна доска, каждый непарный отрезок — своя доска.

Это **точный минимум досок для выбранных рядов** в рамках модели: из одной доски нельзя получить больше одного
начального и одного конечного отрезка (§4.1), поэтому досок на отрезки не меньше `|S| + |E| − M`, и столько
достаточно. `M` считается за один проход: начала по возрастанию, концы по убыванию; если наименьшее свободное
начало и наибольший свободный конец помещаются в доску — это пара, иначе этот конец не помещается ни с одним
началом и остаётся один. (Обмен пар показывает, что такой выбор не уменьшает число пар.)

Каждая доска плана учтена ровно один раз, каждый отрезок взят из одной доски — двойного использования обрезков
нет по построению; порядок рядов на результат не влияет. Остатки досок — отход или неиспользованные обрезки;
повторно они используются только через пары, то есть только с правильным профилем и длиной `≥ m`.

**Ряд короче доски** (`R ≤ l`): стыков нет, схема не влияет. Из доски выходит `q = ⌊l / R⌋` отрезков
(оба торца могут быть срезаны — ряд упирается в стены), `B = ⌈N / q⌉`. Ограничение `m` здесь не применяется:
в ряду нет стыков; если инструкция запрещает и такие отрезки, расчёт для `R < m` — за границами версии 1.

### 4.5 Запас, упаковки, стоимость

- `B_з = ⌈B · (100 + z) / 100⌉` — запас добавляется к доскам плана (считается в целых: `z` в десятых процента).
- Упаковки `P = ⌈B_з / n⌉`; к покупке `P·n` досок, `P·n·l·w` м².
- Стоимость `= P × цена` (в копейках).
- Справочно: `B_A = ⌈L·W / (l·w)⌉` (по площади) и отходы плана `(B·l·w − L·W) / (L·W)`.

Запас `z` — **не** на подрезку (её уже учитывает план), а на брак, ошибки резки, неровные стены, обход
препятствий и порогов. По умолчанию предлагается 5 % с этим пояснением; пользователь может поставить 0.

## 5. Объём версии 1

**Входит:** одна прямоугольная комната; направление вдоль длины или ширины; схемы 1/2, 1/3, «от обрезка»;
минимальный отрезок и смещение (по умолчанию 400 мм, редактируются); запас; цена; результат — упаковки,
доски плана и с запасом, ряды, ширина последнего ряда (с подсказкой выровнять первый и последний ряд,
если `r < 50 мм`), сводка начал/концов рядов по типам, справочный расчёт по площади и отходы.

**Не входит (сценарии за границами версии 1):** Г-образные и непрямоугольные комнаты, ниши, колонны, трубы;
дверные проёмы и заход под коробку; несколько комнат с переносом обрезков; диагональная укладка, ёлочка;
доски разной длины в упаковке; подложка, плинтус, порожки; вычитание компенсационного зазора; ширина пропила
в явном виде; оптимизация раскладки (перебор сдвигов `d`, стартовой стены).

## 6. Допущения

1. Комната — прямоугольник, стены прямые; размеры `L`, `W` измерены по полу.
2. Размеры доски — рабочие (без замка). Проверка: `n·l·w` совпадает с площадью упаковки на этикетке.
3. Компенсационный зазор **не вычитается** — покрывается весь размер комнаты (в сторону запаса); размеры
   вводятся от стены до стены. **Ширина пропила в модели не учитывается** (отрезок и обрезок дают в сумме
   ровно `l`). Это компенсирует невычтенный зазор: в каждом ряду не больше двух отрезков, каждый короче
   расчётного не больше чем на один пропил (~3 мм), а зазор у двух стен (обычно 8–15 мм с каждой стороны)
   больше двух пропилов. Следствия: отрезок, рассчитанный длиной `m`, в натуре может быть короче `m`
   на пропил; пары с `s + e = l` ровно (К9) режутся одним резом. Если в будущем зазор начнут вычитать,
   пропил нужно учесть явно: пара допустима при `s + e + k ≤ l`.
4. Ряды укладываются слева направо от одной стены, обрезки — с правильным профилем (§4.1).
5. `m` и `o` соответствуют инструкции к покрытию; ответственность за их ввод — на пользователе (подсказка).
6. Лишняя полоса последнего ряда (`w − r`) — отход; при выравнивании первого и последнего рядов число рядов то же.
   Порог «узкого» последнего ряда (в интерфейсе — 50 мм) тоже зависит от инструкции.

## 7. Ограничения (что прямо сказать пользователю)

- Это план для идеального прямоугольника, а не схема укладки конкретной комнаты; запас нужен всегда.
- Результат не обязательно минимален: опытный мастер может разложить экономнее (другая стартовая стена,
  другой сдвиг). В плане такого «скрытого» запаса нет — округлений сверх правил §4 не делается.
- Компенсационный зазор не вычитается: если размер комнаты превышает границу на несколько миллиметров, план
  добавляет материал, хотя на практике эти миллиметры уходят в зазор (К10: 2,400 → 10 досок, 2,401 → 13).
- Монотонность по размерам не доказана (схема 1/2, ширина 1 м, длины 2,4–4,8 м с шагом 10 мм — нарушений нет).
- Строгая схема 1/3 при доске 1200 мм и `m = 300` часто невыполнима — калькулятор сообщает об этом, а не
  подбирает «похожую» раскладку (К7б). Приблизительная «треть» (любое смещение `≥ o`) — это схема «от обрезка».
- Результат зависит от направления и схемы; калькулятор считает выбранные пользователем и не ищет лучшие
  (К13: вдоль — 57 досок, поперёк по 1/3 — 56, §10).

## 8. Контрольные примеры

Общее, если не указано иное: доска **1200 × 200 мм**, **8 досок** в упаковке (1,92 м²), `m = o = 300 мм`,
укладка вдоль длины, запас 0 %. Запись ряда: «начало + целые × l + конец → новых досок».
Пошаговая нарезка «→ П / из Л» показывает один из способов получить пары отрезков; число досок во всех примерах
равно `F + |S| + |E| − M` (§4.4) — это проверено отдельно (§10).

### К1. Площадь и ряды делятся нацело — 1/2

2,4 × 1,0 м. `R = 2400`, `N = 1000/200 = 5`. Площадь: 2,4 / 0,24 = **10** досок ровно.
Цикл `[1200, 600]`: `(2400 − 1200) mod 1200 = 0` — ряд из 2 целых; `(2400 − 600) mod 1200 = 600 ≥ 300` — ряд
600 + 1200 + 600. `d = 0`. Чётные ряды (0, 2, 4): по 2 целых = 6. Нечётные (1, 3): начало 600 — новая доска
(левая 600 → Л), 1 целая, конец 600 — из Л ровно = по 2. **B = 10**, упаковок ⌈10/8⌉ = **2**.
Корректно: план совпадает с площадью — отходов нет, обрезок 600 полностью используется в том же ряду.

### К2. Округление площади даёт лишнюю доску; ряды дают больше — 1/2

2,5 × 1,0 м. Площадь: 2,5 / 0,24 = 10,42 → **11** (округление добавляет доску).
Ряды: `R mod l = 100` — конец 100 < 300. Сдвиг: конец чётного ряда `100 + d ≥ 300` → `d ≥ 200`;
начало нечётного `600 − d ≥ 300` → `d ≤ 300`; конец нечётного `700 + d` ✓. **d = 200**: чётные 1000 + 1×1200 + 300,
нечётные 400 + 1×1200 + 900.
Ряд 0: 1000 — новая (левая 200 < 300 — отход), 1 целая, 300 — новая (правая 900 → П) → 3.
Ряд 1: 400 из П(900) (отход 500), 1 целая, 900 — новая (правая 300 → П) → 2.
Ряд 2: 1000 — в П только 300 → новая → 3 (П: 300, 900). Ряд 3: 400 из 900 → 2. Ряд 4: 3.
**B = 13** (по площади 11), упаковок **2**.
Почему 13 — минимум для схемы 1/2 при этих размерах (в рамках модели, при любом допустимом сдвиге — §10): начала 1000 (×3) и концы 900 (×2) не помещаются в одну доску ни с одной
парой (1000 + 300 > 1200, 400 + 900 > 1200), каждой нужна своя доска; две пары 400 + 300 — ещё 2 доски; конец
300 третьего чётного ряда — ещё 1; целых 5. 3 + 2 + 2 + 1 + 5 = 13.

### К3. Число рядов округляется вверх — 1/2

2,4 × 1,05 м. `N = ⌈1050/200⌉ = ⌈5,25⌉ = 6`, последний ряд `1050 − 5·200 = 50 мм` (подсказка: выровнять первый
и последний ряд до (200 + 50)/2 = 125 мм — рядов по-прежнему 6). Ряды как в К1: 3 × 2 + 3 × 2 = **12** досок.
Площадь 2,52 / 0,24 = 10,5 → 11. Упаковок **2**. Корректно: шестой ряд нужен целиком, хотя покрывает 50 мм.

### К4. Вдоль длинной стены — 1/2

3,6 × 1,3 м, вдоль длины: `R = 3600`, `N = ⌈6,5⌉ = 7`, последний ряд 100 мм.
`(3600 − 1200) mod 1200 = 0` → 3 целых; `(3600 − 600) mod 1200 = 600` → 600 + 2×1200 + 600; `d = 0`.
Чётные (4 ряда) × 3 = 12; нечётные (3 ряда): новая на начало 600 (левая 600 → Л), 2 целых, конец 600 из Л → 3 × 3 = 9.
**B = 21**, упаковок ⌈21/8⌉ = **3**. Площадь 4,68 / 0,24 = 19,5 → 20.

### К5. Та же комната поперёк — 1/2

3,6 × 1,3 м, вдоль ширины: `R = 1300`, `N = 3600/200 = 18`.
`(1300 − 1200) = 100` < 300 → сдвиг: `100 + d ≥ 300`, `600 − d ≥ 300` → **d = 200**: чётные 1000 + 300,
нечётные 400 + 900 (целых досок в ряду нет).
Ряд 0: 1000 новая (200 — отход), 300 новая (900 → П) → 2. Ряд 1: 400 из 900, 900 новая (300 → П) → 1.
Ряд 2: 1000 новая, 300 новая (900 → П) → 2. Ряд 3: 400 из 900 → 1. Далее так же: 9 × 2 + 9 × 1 = **27**,
упаковок ⌈27/8⌉ = **4**. Площадь — те же 20 досок.
Почему 27 — минимум для схемы 1/2 при этих размерах (в рамках модели, при любом допустимом сдвиге — §10): 1000 и 900 не сочетаются ни с одним отрезком другого типа в одной доске
(1000 + 300 > 1200; 900 + 400 > 1200), это 18 досок; пары 400 + 300 — ещё 9. **Вывод: направление укладки
меняет расход на 6 досок (+29 %).**

### К6. Смещение на половину доски со сдвигом — 1/2

2,0 × 1,0 м, `N = 5`. Без сдвига конец нечётного ряда `(2000 − 600) mod 1200 = 200` < 300.
Условия: `200 + d ≥ 300` → `d ≥ 100`; `600 − d ≥ 300`; конец чётного `800 + d < 1200` ✓ → **d = 100**:
чётные 1100 + 900 (целых 0), нечётные 500 + 1200 + 300.
Ряд 0: 1100 новая (100 — отход), 900 новая (300 → П) → 2. Ряд 1: 500 — в П только 300 → новая (левая 700 → Л),
1 целая, 300 из Л(700) (отход 400) → 2. Ряды 2, 3, 4 — так же: 2, 2, 2. **B = 10**, упаковок **2**.
Площадь 2,0 / 0,24 = 8,33 → 9. Смещение между рядами 600 мм ✓.

### К7. Смещение на треть доски — 1/3

2,4 × 1,0 м, `t = 400`, цикл `[1200, 800, 400]`: концы 0, 400, 800 — все допустимы, `d = 0`, смещение 400 ≥ 300.
Ряд 0: 2 целых. Ряд 1: 800 новая (левая 400 → Л), 1 целая, 400 из Л → 2. Ряд 2: 400 новая (левая 800 → Л),
1 целая, 800 из Л → 2. Ряд 3: 2 целых. Ряд 4: как ряд 1 → 2. **B = 10** = площадь, упаковок **2**.

### К7б. Схема 1/3 невыполнима

2,5 × 1,0 м, 1/3: концы при `d = 0`: `(2500 − 1200) mod 1200 = 100`, `(2500 − 800) mod 1200 = 500`,
`(2500 − 400) mod 1200 = 900`. Начало `400 − d ≥ 300` → `d ≤ 100`; тогда первый конец `100 + d ∈ [100, 200]` —
всегда короче 300 и не 0. **Допустимого сдвига нет** → ошибка «Схема 1/3 невозможна для этих размеров:
в ряду остаётся отрезок короче 30 см. Выберите 1/2 или „от обрезка“ либо уточните минимальный отрезок».

### К8. Короткий остаток нельзя использовать — «от обрезка»

2,3 × 0,8 м, `N = 4`, `R mod l = 1100` → смещение при прямом переносе обрезка `min(1100, 100) = 100` < 300.
Ряд 0: начало 1200 (конец `1100` ≥ 300 ✓) → целая + конец 1100 новой доской; правая часть **100 мм < 300 —
отход** (её нельзя ставить началом ряда) → 2.
Ряд 1: естественный обрезок 100 < 300 — не подходит → перебор от 1200: смещение с началом 1200 требует `t ∈ [300, 900]`, конец `(2300 − t) mod 1200`
допустим при `t ≤ 800` → **t = 800**: 800 новая (левая 400 → Л), 1 целая, конец 300 из Л(400) (отход 100) → 2.
Ряд 2: естественный обрезок `1200 − 300 = 900` даёт смещение с 800 всего 100 < 300 → перебор: `t = 1200`:
смещение с 800 — 400 ✓, конец 1100 ✓ → как ряд 0 → 2. Ряд 3: как ряд 1 → 2.
**B = 8**, площадь 1,84 / 0,24 = 7,67 → 8, упаковок **1**.

### К9. Остаток используется повторно — «от обрезка»

2,0 × 1,0 м, `N = 5`, `R mod l = 800` → смещение `min(800, 400) = 400` ✓.
Ряд 0: 1200 (конец 800 ✓): целая + 800 новой доской, правая **400 → П** → 2.
Ряд 1: обрезок 400 из П как есть: смещение 400 ✓, конец `(2000 − 400) mod 1200 = 400` ✓ → 400 + 1200 + 400,
конец новой доской, правая **800 → П** → 2.
Ряд 2: обрезок 800: смещение 400 ✓, конец `(2000 − 800) mod 1200 = 0` → 800 + 1200 → 1.
Ряд 3: конец ряда 2 равен 0 — естественного обрезка нет → перебор: 1200, смещение с 800 — 400 ✓ → как ряд 0 → 2.
Ряд 4: как ряд 1 → 2.
**B = 9** = площадь (8,33 → 9), упаковок **2**. Каждые три ряда используют ровно 5 досок без отходов.
Та же комната по схеме 1/2 — 10 досок (К6): схема влияет на расход.

### К10. Изменение на 1 мм меняет количество досок — 1/2

2,400 × 1,0 м — **10** досок (К1). 2,401 × 1,0 м: `R mod l = 1` → конец 1 мм; сдвиг `1 + d ≥ 300` → `d ≥ 299`,
`600 − d ≥ 300` → `d ≤ 300` → **d = 299**: чётные 901 + 1200 + 300, нечётные 301 + 1200 + 900.
Ряд 0: 901 новая (левая **299 < 300 — отход**), 1 целая, 300 новая (900 → П) → 3. Ряд 1: 301 из 900 (отход 599),
1 целая, 900 новая (300 → П) → 2. Ряд 2: 301-миллиметровый обрезок не подходит к началу 901 → 3 (П: 300, 900).
Ряд 3: 300 < 301 — не подходит, берётся 900 → 2. Ряд 4: 3. **B = 13**.
Вывод: +1 мм длины даёт +3 доски. На практике этот миллиметр уходит в компенсационный зазор — модель его
намеренно не вычитает (допущение 3), это нужно объяснить в интерфейсе.

### К11. Упаковки с запасом — 1/2

4,8 × 3,0 м, `N = 15`, `R mod l = 0`, `d = 0`. Чётные ряды (8) × 4 целых = 32; нечётные (7): 600 новая + 3 целых

- 600 из Л = 4 → 28. **B = 60** (= площадь 14,4 / 0,24).

* `z = 0`: ⌈60 / 8⌉ = ⌈7,5⌉ = **8** упаковок;
* `z = 5 %`: `B_з = ⌈60 · 105 / 100⌉ = 63` → ⌈63 / 8⌉ = ⌈7,875⌉ = **8**;
* `z = 10 %`: `B_з = ⌈60 · 110 / 100⌉ = 66` → ⌈66 / 8⌉ = ⌈8,25⌉ = **9**.

Корректно: запас применяется к доскам, упаковки округляются вверх один раз — 5 % помещаются в неполную восьмую
упаковку, 10 % — уже нет.

### К12. Стоимость

К11 с запасом 10 %: 9 упаковок × 1 849,90 ₽ = 184 990 коп. × 9 = 1 664 910 коп. = **16 649,10 ₽**.
Без запаса: 8 × 1 849,90 = **14 799,20 ₽**.

### К13. Реальная доска: площадь меньше плана на упаковку — 1/2, вдоль длины

4,0 × 3,5 м, доска **1380 × 193**, 8 в упаковке (8 · 1,38 · 0,193 = 2,13072 м²).
`N = ⌈3500/193⌉ = ⌈18,13⌉ = 19`, последний ряд `3500 − 18·193 = 26 мм` (подсказка выровнять: (193 + 26)/2 ≈ 110 мм).
Цикл `[1380, 690]`: концы `(4000 − 1380) mod 1380 = 1240` ✓ и `(4000 − 690) mod 1380 = 550` ✓, `d = 0`.
Чётные: 1380 + 1×1380 + 1240 — конец новой доской, правая **140 — отход** → 3. Нечётные: 690 новая (левая 690 → Л),
2 целых, 550 из Л(690) (отход 140) → 3. **B = 19 × 3 = 57**.
По площади: 14 / 0,26634 = 52,56 → 53 доски = ⌈53/8⌉ = **7** упаковок; по плану ⌈57/8⌉ = **8** упаковок.
С запасом 5 %: `⌈57 · 1,05⌉ = 60` → 8 упаковок (17,05 м²). «Площадь + 5 %» = 56 досок — **меньше плана**.
Отходы плана: (57 · 0,26634 − 14) / 14 = 8,4 %.
Граница материала для этих рядов `⌈19 · 4000 / 1380⌉ = 56`: план 57 — не доказанный минимум. Схемы 1/3 и «от обрезка»
вдоль длины тоже дают 57; поперёк по 1/3 — 56 досок = 7 упаковок (проверка §10). Вывод: «площадь занижает»
относится к выбранной раскладке, а не к комнате.

### К14. Ряд короче доски

2,0 × 0,55 м, укладка вдоль ширины: `R = 550 ≤ 1200`, `N = 2000/200 = 10`. Из доски — `⌊1200/550⌋ = 2` отрезка
(остаток 100 — отход), стыков нет. **B = ⌈10/2⌉ = 5** = площадь (1,1 / 0,24 = 4,58 → 5), упаковок **1**.

## 9. Как проверять реализацию

- Тесты по К1–К14 с этими числами (не выводом функции); в К1–К14 явно `m = o = 300`.
- Свойства против независимого симулятора (раскладка ряд за рядом и нарезка досок по парам):
  - в каждом ряду `s + f·l + e = R`;
  - каждый отрезок `≥ m` (кроме случая `R ≤ l`), смещение соседних рядов `≥ o`, для 1/2 и 1/3 — ровно по схеме;
  - каждая пара `s + e ≤ l`, каждый отрезок — ровно в одной доске, пар не больше `min(|S|, |E|)`;
  - баланс: `B·l` = сумма отрезков всех рядов (`N·R`) + отходы + неиспользованные обрезки, все слагаемые `≥ 0`;
  - `B ≥ ⌈N·R / l⌉ ≥ B_A`; `B ≤ F + |S| + |E|` (без повторного использования обрезков);
  - `M` совпадает с перебором всех паросочетаний на малых случаях;
  - при запасе 0 упаковки `= ⌈B / n⌉`; с запасом `⌈⌈B·(1000 + 10z)/1000⌉ / n⌉`; упаковки не убывают с ростом `z`;
  - невыполнимая схема — ошибка с причиной (смещение схемы `< o`, нет допустимого сдвига, ряд `i` в «от обрезка»),
    а не число.
- Ошибки ввода: пустые, нулевые, отрицательные размеры; `m > l`; дробное `n`; запас вне 0–50 %; невыполнимые схемы.

### Подтверждено без изменений

- Профиль замка: правая часть — только начало, левая — только конец, середина — отход; из доски не больше
  одного начала и одного конца. Это основа и нижней оценки, и подсчёта.
- Условия ряда (`s ≥ m`, `e = 0` или `e ≥ m`, сумма `= R`) и круговое смещение.
- Схемы 1/2 и 1/3 сохраняют смещение `⌊l/2⌋` и `t` при любом сдвиге; ряды через один (1/2) и через два (1/3)
  совпадают — это допустимо, соседние — нет.
- «От обрезка»: при переносе обрезка смещение постоянно `min(R mod l, l − R mod l)`; когда оно `< o` или обрезок
  `< m`, срабатывает перебор (К8), стыки соседних рядов не совпадают.
- Числа К1–К14: ряды по §4.3, доски по §4.4 — совпадают с ручным расчётом. Перебор всех `d` с выбором
  меньшего `B` ни в одном примере не дал выигрыша.
- Модельная граница: в каждом ряду отрезков на `R`, рядов `N`, `N·w ≥ D`, поэтому `B·l ≥ N·R` и
  `B ≥ ⌈N·R/l⌉ ≥ ⌈L·W/(l·w)⌉ = B_A`. Это свойство модели (без зазора и пропила), а не универсальная граница
  реального расхода.

### Ручная перепроверка спорных примеров

Обозначения: `Д` — доска; в паре слева конец ряда (левая часть доски), справа начало ряда (правая часть).

**К2.** 2,5 × 1,0 м, 1/2, `l = 1200`, `N = 5`, `R = 2500`. Сдвиг: при `d < 200` конец чётного ряда `100 + d < 300`;
при `d > 300` начало нечётного `600 − d < 300`; `d = 200`. Ряды: 0, 2, 4 — `1000 | 1200 | 300`; 1, 3 — `400 | 1200 | 900`
(суммы 2500 ✓; смещение 600 ✓).
`F = 5`; начала `S = {1000, 1000, 1000, 400, 400}`; концы `E = {300, 300, 300, 900, 900}`. Пары `s + e ≤ 1200`:
только `400 + 300` → `M = 2`. **B = 5 + 5 + 5 − 2 = 13**.
Журнал: Д1–Д5 целые; Д6–Д8: начало 1000, отход 200 (< 300); Д9, Д10: конец 300 + начало 400, отход 500;
Д11: конец 300, остаётся правая 900 (только начало — не нужна); Д12, Д13: конец 900, остаётся правая 300.
**Профиль:** правые 300 из Д12, Д13 геометрически подходят для конца 300 третьего чётного ряда, но по замку — нет;
поэтому нужна Д11. Баланс: 13 · 1200 = 15 600 = 5 · 2500 + (3 · 200 + 2 · 500 + 900 + 300 + 300) = 12 500 + 3 100 ✓.
Упаковки: `⌈13/8⌉ = 2` (по площади 11 досок — тоже 2). Минимум для 1/2 при любом `d ∈ [200, 300]` и любом порядке рядов: длинные начала `1200 − d` и длинные концы
`700 + d` (900–1000 мм) с любым отрезком другого типа дают `1300 мм > 1200`, пары возможны только «короткое начало
`600 − d` + короткий конец `100 + d`» (700 мм), их не больше двух → 13.

**К5.** 3,6 × 1,3 м поперёк, 1/2: `R = 1300`, `N = 18`, `d = 200`. Ряды: 9 × `1000 | 300`, 9 × `400 | 900` (`f = 0`;
суммы 1300 ✓; смещение 600 ✓). `F = 0`, `|S| = |E| = 18`, пары — только `400 + 300` → `M = 9`.
**B = 0 + 18 + 18 − 9 = 27**. Журнал: 9 досок — начало 1000 + отход 200; 9 — конец 900 + остаток 300;
9 — конец 300 + начало 400 + отход 500. Баланс: 27 · 1200 = 32 400 = 18 · 1300 + 9 · (200 + 300 + 500) ✓.
Упаковки `⌈27/8⌉ = 4` (по площади 20 досок = 3). **Профиль:** без правила замка те же отрезки уложились бы
в 21 доску (900 + 300 в одной, три по 400 в одной) — правило добавляет 6 досок. При `d = 300` (начала 900/300,
концы 400/1000) и других допустимых `d` — тоже 27.

**К7б.** 2,5 × 1,0 м, строгая 1/3: начала по циклу — `1200 − d`, `800 − d`, `400 − d` (mod 1200), концы — `100 + d`,
`500 + d`, `900 + d` (mod 1200), всегда через 400 мм. Пусть `u = d mod 400`: наименьшее начало `400 − u ≥ 300` →
`u ≤ 100`; наименьший конец `100 + u ∈ [100, 200]` — не 0 и меньше 300. **Ни один `d` из 0…1199 не подходит** →
ошибка «Строгая схема 1/3 невозможна для этих размеров: конец ряда короче 30 см при любом сдвиге». Те же размеры
по 1/2 и «от обрезка» — 13 досок.

**К9.** 2,0 × 1,0 м, «от обрезка», `R mod l = 800` → смещение при переносе 400 ✓. Ряды: 0 `1200 | 800`;
1 (обрезок 400) `400 | 1200 | 400`; 2 (обрезок 800) `800 | 1200`; 3 (конец 0 → перебор, 1200: смещение 400 ✓)
`1200 | 800`; 4 (обрезок 400) `400 | 1200 | 400`. Суммы 2000 ✓, смещения 400 ✓, отрезки ≥ 300 ✓.
`F = 5` (начала-целые в рядах 0, 3 и по одной целой в рядах 1, 2, 4); `S = {400, 800, 400}`, `E = {800, 400, 800, 400}`;
пары `400 + 800`, `800 + 400`, `400 + 800` → `M = 3`. **B = 5 + 3 + 4 − 3 = 9**. Журнал: Д6 — конец 800 (ряд 0) +
начало 400 (ряд 1), один рез; Д7 — конец 400 (ряд 1) + начало 800 (ряд 2); Д8 — конец 800 (ряд 3) + начало 400 (ряд 4);
Д9 — конец 400 (ряд 4), остаётся правая 800. Баланс 9 · 1200 = 5 · 2000 + 800 ✓. Упаковки `⌈9/8⌉ = 2`.

**К10.** 2,401 × 1,0 м, 1/2: конец чётного ряда `1 + d ≥ 300` → `d ≥ 299`, начало нечётного `600 − d ≥ 300` →
`d ≤ 300`; `d = 299`. Ряды 0, 2, 4 — `901 | 1200 | 300`; 1, 3 — `301 | 1200 | 900` (суммы 2401 ✓). `F = 5`,
`S = {901 ×3, 301 ×2}`, `E = {300 ×3, 900 ×2}`; пары: `301 + 300 = 601` ✓ ×2, `901 + 300 = 1201` ✗, `301 + 900 = 1201` ✗ →
`M = 2`, **B = 13**. Механизм скачка: при 2,400 пары `600 + 600 = 1200` помещаются в доску, при 2,401 все «длинные»
пары превышают доску на 1 мм. Баланс: 13 · 1200 = 5 · 2401 + 3 595 (3 · 299 + 2 · 599 + 2 · 300 + 900) ✓.
Упаковки 2 и 2 — скачок в досках не меняет число упаковок.

### Что пока нельзя надёжно реализовать

- Утверждения о минимальной покупке для комнаты (без перебора направлений, схем, стартовых стен) — только
  «для выбранной раскладки».
- Вычитание компенсационного зазора и явный пропил — нужны значения из инструкции и пересмотр К1–К14.
- Комнаты сложной формы, проёмы, препятствия, перенос обрезков между комнатами.

### Рекомендация

Модель 1.1 достаточно ограничена и проверяема для реализации: ряды строятся детерминированно (§4.3), доски
считаются точной формулой (§4.4) без симуляции нарезки, все утверждения отнесены к выбранной раскладке.
Можно переходить к этапу 3.1. Дополнительно упрощать модель не нужно.
