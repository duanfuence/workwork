# Ориентиры расхода: краска, штукатурка, шпаклёвка

Дата проверки: **2026-10-26**. Используются в `src/data/material-presets.ts` (выбор «Тип материала» рядом с полем
расхода) и в таблицах на страницах калькуляторов.

## Как собирались данные

- Только официальные сайты производителей, которые продаются в России, — страницы продуктов и технические описания
  (`knauf.ru`, `knauf.com`, `volma.ru`, `bergauf.ru`, `ceresit.ru`, `osnovit.ru`, `starateli.ru`, `tikkurila.ru`,
  `parade.ru`, `dufa.ru`). Магазины, обзоры и пересказы не учитывались.
- **Ограничение проверки.** Сеть среды разработки закрыта политикой окружения: страницы производителей не
  открывались напрямую. Значения взяты из поисковой выдачи по официальным доменам — в большинстве случаев это
  дословные цитаты характеристик со страниц продуктов (например, «Расход сухой смеси при толщине 10 мм 8-9 кг на
  1 кв.м.»). Перед публикацией стоит открыть страницы по ссылкам и сверить числа.
- Тип добавлялся в код, только если нашлось не меньше трёх производителей.

## Правило выбора ориентира

Ориентир — **типичный продукт на консервативной стороне**, а не самый расходный из найденных:

- для расхода (кг/м²) — **медиана верхних границ** проверенных продуктов, округлённая **вверх** до 0,1;
- для укрывистости (м²/л) — **медиана нижних границ**, округлённая **вниз** до целого (меньше квадратных метров на
  литр — больше литров).

У продукта с одним числом обе границы равны этому числу. При чётном числе продуктов медиана — среднее двух средних.

**Почему разброс покрывает запас, а не ориентир.** В каждом калькуляторе есть поле «Запас» (по умолчанию 10 %) — на
неровности, впитывание и потери. Если ориентир уже взят по самой расходной марке, запас добавляется второй раз сверху:
для массовых смесей это переплата. Пример прежнего правила: гипсовая штукатурка по ориентиру 1,3 кг/(м²·мм) (верхняя
граница Bergauf) при запасе 10 % давала 1,43 кг на 1 мм — в 1,7 раза больше Ротбанда (0,85). Медиана с запасом —
1,1 кг, это выше всех проверенных марок, кроме Bergauf. Для тяжёлой смеси человек увеличит запас или введёт число с
мешка — пометка в результате показывает весь разброс и просит сверить с упаковкой.

Тест в `material-presets.test.ts` пересчитывает каждый ориентир по правилу (`presetValueByRule` в `src/lib/presets.ts`)
и сверяет с данными; отдельно проверяется, что значение лежит в разбросе.

### Расчёт по типам

| Тип                          | Границы продуктов            | Медиана                        | Ориентир   |
| ---------------------------- | ---------------------------- | ------------------------------ | ---------- |
| Краска водно-дисперсионная   | нижние: 7; 7; 8,5; 12        | (7 + 8,5) / 2 = 7,75 → вниз    | **7 м²/л** |
| Штукатурка гипсовая          | верхние: 0,85; 0,9; 1,0; 1,3 | (0,9 + 1,0) / 2 = 0,95 → вверх | **1,0**    |
| Штукатурка цементная         | верхние: 1,5; 1,6; 1,6; 1,8  | (1,6 + 1,6) / 2 = 1,6          | **1,6**    |
| Шпаклёвка гипсовая стартовая | верхние: 0,9; 1,0; 1,0       | 1,0                            | **1,0**    |
| Шпаклёвка гипсовая финишная  | верхние: 0,9; 0,9; 1,0       | 0,9                            | **0,9**    |
| Шпаклёвка полимерная паста   | верхние: 1,6; 1,7; 1,7       | 1,7                            | **1,7**    |

Штукатурка — кг/(м²·мм), шпаклёвка — кг/м² при слое 1 мм. Изменились гипсовая штукатурка (1,3 → 1,0), цементная
(1,8 → 1,6) и финишная шпаклёвка (1,0 → 0,9); остальные совпали с прежним правилом.

## Что не добавлено

- Цементные шпаклёвки и отдельные типы красок (фасадные, для влажных помещений, потолочные) — не просили и не
  проверяли; для них подходит своё значение с упаковки.
- Отдельный ориентир «по ровной невпитывающей поверхности» для краски (10–14 м²/л) — не добавлен, чтобы не
  предлагать заниженный расход: при первом слое по свежей шпаклёвке поверхность впитывающая.
