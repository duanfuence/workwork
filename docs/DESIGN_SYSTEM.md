# Дизайн-система

Светлый, спокойный, минималистичный стиль. Источник значений — `src/styles/tokens.css`.
Компоненты используют только семантические токены (`--color-text`, `--space-4`), а не палитру напрямую.

## Цвета

| Токен                              | Значение              | Назначение                         |
| ---------------------------------- | --------------------- | ---------------------------------- |
| `--color-bg`                       | `#f7f7f4`             | фон страницы (тёплый светлый)      |
| `--color-surface`                  | `#ffffff`             | карточки, шапка, подвал            |
| `--color-surface-muted`            | `#efefea`             | фон второстепенных секций, hover   |
| `--color-text`                     | `#1c1f1d`             | основной текст                     |
| `--color-text-secondary`           | `#3e423f`             | вторичный текст, ссылки меню       |
| `--color-text-muted`               | `#636662`             | подписи, пояснения                 |
| `--color-border`                   | `#e2e2db`             | границы карточек                   |
| `--color-border-strong`            | `#cfcfc6`             | поля ввода, кнопки                 |
| `--color-accent`                   | `#1d6b57`             | акцент: ссылки, фокус, логотип     |
| `--color-accent-hover` / `-active` | `#175747` / `#114236` | состояния акцента                  |
| `--color-accent-soft`              | `#ecf5f1`             | мягкий фон акцента (бейдж статуса) |
| `--color-badge-soon-*`             | `#fbf3e2` / `#7a4f0b` | бейдж «Скоро»                      |
| `--color-danger`                   | `#b42318`             | текст ошибки, рамка поля с ошибкой |
| `--color-danger-soft`              | `#fdf0ee`             | фон поля с ошибкой                 |

Контраст основных пар (WCAG 2.x, рассчитан): текст на фоне — 15.5:1; `--color-text-muted` на `--color-bg` — 5.4:1,
на `--color-surface-muted` — 5.05:1; белый на `--color-accent` — 6.4:1; акцент на фоне — 5.9:1;
бейдж «Скоро» — 6.45:1; `--color-danger` на белом — 6.6:1, на `--color-danger-soft` — 5.9:1.
Все пары не ниже AA (4.5:1).

## Типографика

- Системные шрифты (`--font-sans`) — нет загрузки веб-шрифтов, кириллица везде отображается корректно.
- Размеры: `xs` 13, `sm` 14, `md` 16 (основной текст), `lg` 18, `xl` 22 px;
  `2xl` и `3xl` — адаптивные через `clamp()` (заголовки секций и H1).
- Основной текст не меньше 16 px (в том числе поле поиска — иначе iOS увеличивает страницу при фокусе).
- Межстрочный интервал: 1.2 (заголовки), 1.35, 1.6 (текст).

## Отступы, раскладка

- Шкала с шагом 4 px: `--space-1` (4) … `--space-16` (64).
- Контейнер: максимум 72rem (1152 px), боковые поля 16 px на мобильных и 24 px от 768 px.
- Точка перелома: 48rem (768 px). Сетки карточек — `auto-fill` с минимумом 17rem, без медиазапросов.
- Минимальная зона нажатия — `--tap-target-min` (44 px).

## Радиусы и границы

- Радиусы: `sm` 6, `md` 10 (кнопки, поля), `lg` 14 px (карточки), `pill` (бейджи).
- Граница: 1 px `--color-border`; `--border-strong` для полей ввода.
- Тени: `--shadow-sm` (карточки), `--shadow-md` (наведение, выпадающее меню).

## Состояния

| Состояние | Правило                                                                                                                 |
| --------- | ----------------------------------------------------------------------------------------------------------------------- |
| hover     | фон `--color-surface-muted` (меню, кнопки), граница `--color-accent` (доступные карточки)                               |
| focus     | `:focus-visible` → двойное кольцо `--focus-ring` (белое + акцентное); у поля поиска — акцентная граница и мягкое кольцо |
| active    | `--color-accent-active`                                                                                                 |
| disabled  | `--opacity-disabled` (0.5)                                                                                              |
| «Скоро»   | карточка без ссылки и без hover-эффекта, бейдж `badge--soon`                                                            |

Анимации 120–200 мс; при `prefers-reduced-motion: reduce` отключаются.

## Компоненты

- `SiteHeader` — липкая шапка, логотип, меню (сворачивается на мобильных).
- `CatalogSearch` — поле поиска по каталогу.
- `CalculatorCard` — карточка калькулятора: категория, бейдж статуса, название, описание.
  Для доступного калькулятора кликабельна вся карточка.
- `CategoryCard` — категория и честная сводка («6 калькуляторов в первой очереди» / «появятся позже»).
- `SiteFooter` — название, оговорка об ориентировочности расчётов, навигация, год.
- `Breadcrumbs` — навигационная цепочка, текущая страница с `aria-current="page"`.
- `NumberField` — поле числа: подпись над полем, единица измерения внутри справа, подсказка и ошибка под полем,
  высота не меньше 44 px, шрифт 16 px. Ошибка: рамка и фон `danger`, текст ошибки, `aria-invalid`.
- `.button--primary` / `.button--secondary` — основное и второстепенное действие.
- Страница калькулятора (`calculator.css`): группы полей — карточки-`fieldset` с заголовком; пометка
  «необязательно» ставится у группы, а не у каждого поля (иначе подписи переносятся по-разному и поля
  в ряду не выравниваются). Блок результата — карточка с акцентной полосой сверху, крупное итоговое число,
  список промежуточных величин; на ширине от 960 px — справа от формы и закреплён при прокрутке.
- Доступная карточка калькулятора на главной показывает «Рассчитать →» — на сенсорных экранах нет hover.

## Запрещено

Случайные стоковые изображения, иконочные шрифты, тяжёлые UI-библиотеки, копирование чужих сайтов,
«сырые» hex-цвета в компонентах (кроме белого внутри SVG логотипа).
