# ДомРасчёт

Бесплатный русскоязычный сайт калькуляторов для ремонта и строительства.
Сейчас: технический каркас и главная страница; калькуляторы в разработке.

```bash
npm ci            # установка зависимостей
npm run dev       # локальный сервер разработки
npm run check     # типы, линтер, форматирование, тесты, сборка
```

Требуется Node.js ≥ 22.22.0. Правила работы — [CLAUDE.md](CLAUDE.md), документация — [docs/](docs/).
